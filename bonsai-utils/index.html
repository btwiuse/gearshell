Bonsai Cache Manager

Inspect, export, and delete the bitgpu GGUF cache that the Bonsai app actually uses on this origin. Bitgpu stores downloaded model bytes in a Cache Storage entry, a Cache header entry, and an IndexedDB whose records cover the rest of the file. Cache Storage is partitioned by origin, so to move a model between https://gear.sh/bonsai-utils/ and a http://localhost:PORT/bonsai-utils/ instance you must either export / import on the same origin, or reload the GGUF from Hugging Face.
